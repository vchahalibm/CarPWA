DriveDeck Trainer

A dataset is pictures with boxes around the things to find, each box with a class. Make one, then add pictures (or a zip in YOLO layout), label them, or capture your own web pages to have them labeled for you.

New dataset

Drag to draw a box with the chosen class (keys 1–9 pick one). Click a box to select it, drag to move it, Delete removes it. ← → previous / next picture (saves). Unsaved changes are kept when you switch pictures.
Opens your own pages in a headless browser at the screen sizes and themes you pick, takes screenshots and labels every visible button, link, field, checkbox, select, tab, icon and image from the page itself. Give your controls data-testids and roles and the labels get even better. Needs pip install playwright && playwright install chromium.
